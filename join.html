Install guide

Install BCR in five steps

The mod downloads straight from this site. The goal is zero extra dependencies, so you just install the mod and play. If anything else turns out to be required, it'll be listed here at release.

1

Get Minecraft Java Edition

BCR is a Java Edition mod for Minecraft 1.21.1. Bedrock isn't supported.

Java 1.21.1
2

Install the mod loader

The mod loader is being finalized and will be announced before release.

TBA
3

Download the BCR mod

Grab the latest build of the mod. One file, no modpack needed.

4

Drop it in your mods folder

Put the .jar file in your mods folder. On Windows, press Win + R, type %appdata%\.minecraft and open mods (create it if it doesn't exist).

5

Launch & play

Start the game with the loader profile, then go to Multiplayer → Add Server and enter Revealed at launch. You can also start a singleplayer world.
